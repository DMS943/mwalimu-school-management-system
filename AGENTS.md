# Kiro Agent Configuration

This file contains agent-specific rules and configurations for the Mwalimu School Management System.

## Project Structure
- **Backend**: Django REST Framework with PostgreSQL
- **Frontend**: React SPA with Vite and TypeScript  
- **Routing**: React Router DOM (not Next.js)
- **Build System**: Vite (not Next.js)

## Development Guidelines
- Use Vite for development and building
- Follow React SPA patterns with React Router
- Maintain TypeScript strict mode for type safety
- Use the existing component structure in `src/components/`
